# My Little Dog — Prototype 0.1

A mobile-first static browser prototype for a mischievous adolescent tricolor beagle.

## Features
- Responsive living-room scene and beagle character presentation
- Mood, hunger, energy and bond meters with localStorage persistence
- Pet, feed, play, rest and call interactions
- Autonomous idle messages and gradual needs drift
- User-provided audio import for authentic beagle bark/baying/whining recordings

## Run locally
Open `index.html` in a modern browser. No Node.js build step is required.

## GitHub Pages
1. Upload the complete folder contents to the repository root (keep `index.html` at root).
2. In Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`.
3. Save and open the Pages URL.

## Audio note
No authentic dog recording is bundled in this prototype. Use the speaker button to load a legally obtained beagle recording from your device. The prototype deliberately does not synthesize fake barking.

## Current visual limitation
The beagle image is a concept-derived portrait panel, not a fully separated animation rig. Next asset pass should create clean transparent character poses / sprite frames for idle, walk, run, bark and rest.
